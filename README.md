# Python Factorial Program

## About

This repository contains a simple Python program, `factorial.py`, that calculates the factorial of a number entered by the user.

The program uses a `for` loop to multiply integers from `1` to the given number and prints the calculated factorial.

## File Structure

```text
python-beginner/
└── factorial.py
```

## How to Run

### Prerequisites

* Python 3 installed on your computer.

### Steps

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run the following command:

```bash
python factorial.py
```

If your system uses `python3` to run Python, use:

```bash
python3 factorial.py
```

4. Enter a number when prompted.

## Learning Objectives

This program helps beginners understand:

* **User Input:** Accepting a number using `input()`.
* **Type Conversion:** Converting input into an integer using `int()`.
* **Loops:** Using a `for` loop to repeat calculations.
* **Variables:** Storing and updating the factorial value.
* **Arithmetic Operations:** Multiplying integers to calculate a factorial.
* **Output:** Displaying the result using `print()`.

## Concept

The factorial of a non-negative integer `n`, written as `n!`, is the product of all positive integers from `1` to `n`.

Mathematically:

* `0! = 1`
* `1! = 1`
* `5! = 5 × 4 × 3 × 2 × 1 = 120`

## Purpose

This project is intended for Python beginners who want to practise basic programming concepts, including input handling, loops, variables, and arithmetic operations.
